fndare#

pub fn dare( a : @linear.Matrix, b : @linear.Matrix, q : @linear.Matrix, r : @linear.Matrix, tolerance? : Double?, max_iterations? : Int32?, ) -> @linear.Matrix

The discrete algebraic Riccati equation solved by value iteration P' = A^T P A - A^T P B (R + B^T P B)^-1 B^T P A + Q starting from P = Q; returns the optimal cost-to-go matrix P.

pub fn lqr_gain( a : @linear.Matrix, b : @linear.Matrix, q : @linear.Matrix, r : @linear.Matrix, tolerance? : Double?, max_iterations? : Int32?, ) -> @linear.Matrix

The optimal static state feedback gain K = (R + B^T P B)^-1 B^T P A for the closed loop u = -K x.

fnpure_pursuit#

pub fn pure_pursuit( wheelbase : Double, lookahead : Lookahead, speed? : Double?, ) -> Steering

Pure pursuit: with a lookahead point at (l, y) ahead and to the left, the heading error is theta = atan2(y, l) and the path curvature is kappa = 2 sin(theta) / l; the front-wheel angle follows the bicycle geometry angle = atan(wheelbase * kappa).

fnscurve_plan#

pub fn scurve_plan( distance : Double, v_max : Double, a_max : Double, j_max : Double, ) -> Scurve

Plan the minimal-time jerk-limited rest-to-rest profile from the origin to distance (which may be negative), respecting v_max, a_max and j_max.

fnstanley#

pub fn stanley( kp : Double, heading_error : Double, y : Double, v : Double, v_min? : Double?, ) -> Steering

Stanley: the classic longitudinal + lateral law. With a heading error heading_error (robot orientation relative to the path tangent) and a lateral offset y, the command is angle = heading_error + atan(-kp * y / max(v, v_min)).

fnastar#

pub fn astar(g : Grid, start : Int32, goal : Int32) -> Array[Int32]?

A* search from start to goal with a Manhattan-distance heuristic, which is admissible and consistent for 4-connected movement, so the first pop of the goal holds a path of the fewest steps. Returns the path as flat cell indices including both ends, or None when the goal is unreachable.

fndijkstra#

pub fn dijkstra(g : Grid, start : Int32, goal : Int32) -> Array[Int32]?

Uniform-cost search from start to goal. On a unit-cost grid the shortest path is the fewest-step one. Returns the path as flat cell indices including both ends, or None when the goal is unreachable.
