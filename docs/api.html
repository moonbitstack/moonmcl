fncholesky#

pub fn cholesky(a : Mat) -> Mat raise Refused

The lower Cholesky factor of a symmetric positive-definite matrix a, so that a = l * l^T.

The factor is what the Kalman gain is solved with: a Cholesky solve costs half an LU solve and never needs pivoting for a covariance.

fneigh#

pub fn eigh(a : Mat, sweeps? : Int32) -> Eigh raise Refused

The symmetric eigendecomposition of a by cyclic Jacobi rotations.

The rotations are stable for the covariance-shaped matrices this library hands it, and they need no shift strategy. Only the symmetric part of a is used, so a small skew from rounding does not matter. Raises Refused::Dimension when a is not square and Refused::Exceeded when the sweep limit is reached.

fnexpm#

pub fn expm(a : Mat, terms? : Int32) -> Mat raise Refused

The matrix exponential of a square matrix, by scaling and squaring followed by a truncated Taylor series.

This is what turns a continuous state matrix into a discrete one; the scaling keeps the series inside the range where twenty terms reach machine precision.

fnbox_qp#

pub fn box_qp( h? : @linear.Mat, f? : @linear.Vec, lower? : @linear.Vec, upper? : @linear.Vec, config? : QpConfig, ) -> @linear.Vec raise @linear.Refused

The minimiser of 0.5 z' h z + f' z inside the box [lower, upper].

ADMM rather than an active-set method: the horizon of a predictive controller is re-solved every period with the same h, so a method whose cost per iteration is one triangular solve and one clamp keeps the period short, and there is no active set to warm start.

fncbf_filter#

pub fn cbf_filter( nominal? : @linear.Vec, gradient? : @linear.Vec, drift? : Double, barrier? : Double, alpha? : Double, lower? : @linear.Vec, upper? : @linear.Vec, config? : CbfConfig, ) -> @linear.Vec

The safe input closest to the nominal one.

The barrier h is the one the caller computed for the current state; gradient is d h / d u, drift is d h / d t without the input, and alpha is the class-K gain that decides how hard the filter pushes towards a larger barrier. The result satisfies drift + gradient * u + alpha * barrier >= 0 inside the box, or the closest point to that set when the box and the half-space do not meet.

Dykstra's alternating projection rather than plain alternation: plain alternation lands on a point of the intersection but not on the nearest one, and the whole point of a safety filter is to change the command as little as possible.

fndare#

pub fn dare( a? : @linear.Mat, b? : @linear.Mat, q? : @linear.Mat, r? : @linear.Mat, iterations? : Int32, tolerance? : Double, ) -> Riccati raise @linear.Refused

Solve the discrete algebraic Riccati equation for (a, b) at the weights (q, r) by iterating the Riccati recursion to a fixed point.

The recursion is monotone from p = q, so it converges to the stabilising solution without a Schur decomposition. A system that cannot be stabilised does not converge, and the iteration says so with Refused::Exceeded rather than returning a gain that would drive it further away.

fnilqr#

pub fn ilqr( model? : &@contract.Model, start? : @linear.Vec, goal? : @linear.Vec, controls? : Array[@linear.Vec], dt? : Double, config? : IlqrConfig, ) -> Array[@linear.Vec] raise @linear.Refused

The input sequence that drives start to goal over the horizon the initial guess fixes.

The initial guess gives the horizon, the control dimension and the region the solve starts in; the returned sequence has the same length. The backward pass uses the model's state Jacobian and a central difference for the input one, because a plant contract only promises the former.

A PID configuration from the three gains. A negative gain is refused: a loop with a negative proportional gain is unstable by construction, and refusing it here names the mistake where it is made.

fnrts#

pub fn rts( states? : Array[@linear.Vec], covariances? : Array[@linear.Mat], transitions? : Array[@linear.Mat], process? : @linear.Mat, ) -> (Array[@linear.Vec], Array[@linear.Mat]) raise @linear.Refused

The Rauch-Tung-Striebel smoother: the forward filter's estimates refined by a backward pass over the same record.

states and covariances are the filtered estimates, transitions the state matrices between consecutive steps, and process the process covariance. The result is the smoothed state and covariance at every step, whose covariances are never larger than the filtered ones.
